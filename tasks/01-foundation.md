# Task 01 — Project Foundation

## Objective

Create the basic design system and global layout.

## Work

1. Review the existing Nuxt project.
2. Install only required Nuxt modules.
3. Configure `nuxt.config.ts`.
4. Create CSS files:
   - reset.css
   - variables.css
   - base.css
   - layout.css
   - components.css
   - utilities.css
   - main.css
5. Create:
   - SiteHeader.vue
   - MainNavigation.vue
   - MobileNavigation.vue
   - SiteFooter.vue
   - SiteContainer.vue
6. Create the default layout.
7. Update app.vue.
8. Add placeholder pages for:
   - Home
   - Shop
   - Categories
   - About
   - Blog
   - Contact

## Constraints

- Keep the brand general.
- Do not create restaurant-specific navigation.
- Do not build product functionality yet.
- Do not install a UI framework.

## Acceptance criteria

- The application runs.
- Navigation works.
- Layout is responsive.
- Mobile navigation is usable.
- Typecheck passes.
- Production build passes.
